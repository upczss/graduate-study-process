# HW10：Adversarial Attack

这次作业研究对抗攻击。攻击者在原图上加入很小的扰动，使人眼看起来没有明显变化，但分类模型会产生错误预测。任务使用 200 张 CIFAR-10 图片，并通过代理模型生成能够迁移到未知模型的对抗样本。

## 一、数据和代理模型

```python
CLASSES = (
    "airplane", "automobile", "bird", "cat", "deer",
    "dog", "frog", "horse", "ship", "truck",
)
```

数据共有 10 类，每类 20 张图片。图片尺寸为 `32×32`，文件夹名称本身就是正确标签。

```python
class NormalizedModel(nn.Module):
    def forward(self, images):
        images = (images - self.mean) / self.std
        return self.model(images)
```

攻击过程使用 `[0,1]` 范围的原始像素，输入模型之前再进行 CIFAR-10 标准化。这样既符合预训练模型的输入要求，也更容易控制实际像素变化。

```python
model = get_model("resnet110_cifar10", pretrained=True)
model.eval()
```

助教模型是不可见的黑盒模型，因此需要使用公开的 CIFAR-10 预训练模型作为代理模型。攻击时先计算代理模型的梯度，再利用对抗样本的迁移性攻击其他未知模型。

## 二、扰动约束

```python
epsilon = 8 / 255

adv = torch.maximum(
    torch.minimum(adv, original + epsilon),
    original - epsilon,
)
adv = adv.clamp(0.0, 1.0)
```

作业规定 `L∞ ≤ 8`，表示任意一个像素通道最多只能改变 8。图片已经缩放到 `[0,1]`，所以代码中需要使用 `8/255`。

每次迭代后都把对抗图片限制在 `original ± epsilon` 内，同时限制到合法像素范围。这个过程叫做投影或 clipping。

## 三、FGSM

```python
inputs = images.detach().requires_grad_(True)
loss = F.cross_entropy(model(inputs), labels)
gradient = torch.autograd.grad(loss, inputs)[0]

adv = images + epsilon * gradient.sign()
```

FGSM 只更新一次图片。这里沿着 loss 增大的方向修改像素，使模型更难预测出正确类别。

`gradient.sign()` 只保留梯度的正负方向，让每个像素分别增加或减少 `epsilon`。FGSM 运行速度快，但生成的扰动可能过度依赖当前代理模型。

本次使用 `resnet20_cifar10` 测试完整 200 张图片：

```text
原图准确率：94.5%
FGSM 后准确率：33.0%
最大像素变化：8
```

这个准确率只表示对当前代理模型的攻击效果，不代表未知黑盒模型一定也会降到相同水平。

## 四、I-FGSM

```python
for _ in range(steps):
    gradient = compute_gradient(model, adv, labels)
    adv = adv + alpha * gradient.sign()
    adv = project_linf(adv, original, epsilon)
```

I-FGSM 把一次大更新拆成多次小更新。默认设置为 20 步，每步改变 `0.8/255`，但最终总扰动仍然不能超过 `8/255`。

多次迭代通常能更彻底地攻击代理模型，但也可能过度拟合代理模型参数，导致黑盒迁移能力下降。

## 五、MI-FGSM

```python
scale = gradient.abs().mean(
    dim=(1, 2, 3),
    keepdim=True,
).clamp_min(1e-12)

momentum = decay * momentum + gradient / scale
adv = adv + alpha * momentum.sign()
```

MI-FGSM 在迭代攻击中加入动量。当前梯度先进行归一化，再和前几步的方向累积。

动量可以减少单次梯度波动，让更新方向更稳定，也能降低攻击陷入代理模型局部特征的可能性，因此通常比普通 I-FGSM 更适合黑盒迁移攻击。

## 六、DIM

```python
resize = torch.randint(32, 37, ()).item()
resized = F.interpolate(images, size=(resize, resize))
padded = F.pad(resized, (left, right, top, bottom))
diverse = F.interpolate(padded, size=(32, 32))
```

DIM 会在计算梯度前随机缩放和填充图片，相当于给攻击过程加入数据增强。

如果扰动在图片发生轻微变化后仍然有效，就说明它没有只记住某个代理模型和固定输入形式。这样的扰动通常具有更好的迁移性。

## 七、Ensemble Attack

```python
logits = [model(images) for model in self.models]
ensemble_logits = torch.stack(logits).mean(dim=0)
```

单模型攻击容易只针对一个网络的参数特点。Ensemble Attack 同时使用多个代理模型，并对它们的 logits 求平均，再计算统一的 loss 和梯度。

```python
models = (
    "nin_cifar10",
    "resnet20_cifar10",
    "preresnet20_cifar10",
)
```

不同结构共同认为有效的攻击方向，更可能对未知模型也有效。代价是显存占用和运行时间会随模型数量增加。

## 八、保存和检查图片

```python
pixels = (
    adv.mul(255)
    .round()
    .clamp(0, 255)
    .byte()
)
```

对抗图片最终需要保存成 PNG，所以要把 `[0,1]` 张量还原到 `[0,255]` 并取整。保存后还需要重新读取图片，检查实际整数像素差。

```python
difference = np.abs(
    adversarial.astype(np.int16)
    - original.astype(np.int16)
)

assert difference.max() <= 8
```

不能只检查保存前的浮点张量，因为取整和图片编码可能改变结果。PNG 是无损格式，不会像 JPEG 一样额外改变像素。

## 九、JPEG 防御

```python
quality = 100 - compression

image.save(
    buffer,
    format="JPEG",
    quality=quality,
)
```

作业中的 `compression rate=70%` 对应约 `JPEG quality=30`。JPEG 压缩会丢弃一部分高频细节，而对抗扰动经常隐藏在这些细小变化中，因此压缩可能减弱攻击。

![](outputs_test/defense/defense_comparison.png)

本次使用 `resnet110_cifar10` 对 `dog2.png` 进行实验：

```text
原图：dog，99.64%
FGSM 后：cat，72.27%
JPEG 防御后：dog，99.37%
```

FGSM 成功把狗误判为猫。经过 JPEG 压缩后，模型重新预测为狗，说明压缩去除了部分有效的对抗噪声。

JPEG 防御并不是绝对安全的。攻击者如果在生成对抗样本时把 JPEG 处理也考虑进去，仍然可能绕过这种简单防御。
